# AgentOS Mobile — Unified Autonomous Mobile Command Center

**AgentOS Mobile** is the outcome-driven mobile application for iOS & Android built according to the core principles of `world_rocking_agentic_app_ideas.md`. It turns agentic intelligence into a trusted personal operator.

## Core Mobile UX Principles

1. **Outcome Cards:** Shows measurable outcomes at a glance rather than raw chat dialogs ($24k recovered, 94% auto-resolved, $740 saved/yr).
2. **Universal Approval Stack:** A single unified queue for one-tap biometric and human-in-the-loop approvals for payments, cancellations, and clinical signatures.
3. **Emergency Kill-Switch Bar:** Direct tactile switch to quarantine or halt agents instantly.
4. **Multi-Agent Navigation:** Switch fluidly between **CashHound**, **ResolveX**, **SentinelMesh**, **LocalRoar**, **PulseMD**, and **OmniLife**.

## Running the Mobile App

```sh
# Start Expo development server
npm start

# Run iOS simulator
npm run ios

# Run Android emulator
npm run android

# Run test suite
npm test
```
