AgentOS Developer Documentation

AgentOS is an outcome-driven, production-grade operating system for autonomous AI agents, published under the official scope @spekra.in/agent-os. It combines zero-trust governance, speculative action verifiers, cross-agent memory graphs, auto-healing execution rails, and live Gemini AI integration.

1. Installation

Install the official runtime SDK and CLI tools from npm:

bash 
npm install @spekra.in/agent-os

2. Quickstart

Import core engines directly in your Node.js application (ES Modules):

javascript 
import {
  SpeculativeVerifier,
  AgentOSLLMGateway,
  AgentMemoryGraph,
  SentinelGovernor,
  AgentOSSwarm
} from '@spekra.in/agent-os';

// 1. Audit high-value transactions with SpeculativeVerifier
const verifier = new SpeculativeVerifier();
const audit = verifier.verifyAction({
  id: 'act-101',
  amountCents: 45000,
  breakdown: [{ amountCents: 45000 }],
  title: 'Service Remittance',
  description: 'Friendly invoice reminder'
});

console.log('Action Approved:', audit.verified); // true
console.log('Policy Score:', audit.policyAlignmentScore); // 100

3. Gemini AI Gateway gemini-2.5-flash

The AgentOSLLMGateway integrates Google Gemini models with mandatory pre-flight speculative verification. If Gemini hallucinates or uses coercive language, the verifier intercepts the action before execution.

javascript 
import { AgentOSLLMGateway } from '@spekra.in/agent-os';

// Automatically reads process.env.GEMINI_API_KEY
const gateway = new AgentOSLLMGateway({
  model: 'gemini-2.5-flash'
});

// Generates empathetic, FDCPA-compliant dunning notice
const result = await gateway.generateDunningNotice({
  invoiceId: 'INV-2026',
  customerName: 'Acme Logistics',
  amountCents: 84000,
  daysPastDue: 35,
  tone: 'professional',
  discountPercent: 10
});

console.log('Provider:', result.provider);
console.log('Verified:', result.audit.verified);
console.log('Message:', result.text);

4. Speculative Verifier ("Second Pair of Eyes")

Every proposed agent action is audited prior to human presentation or automated execution.

  • Integer Math Check: Ensures breakdown.reduce(sum) === amountCents without floating point drift.
  • Regulatory Coercion Filter: Blocks illegal threats under debt collection law (e.g. /police|arrest|jail|seize property/i).
  • Dual-Control Threshold: Actions exceeding $10,000 (1,000,000 cents) automatically require secondary executive approval.

5. Cross-Agent Memory Graph Zero-Leak Fabric

Guarantees that sensitive facts cannot leak across agent boundaries through cryptographic privacy tiers:

javascript 
import { AgentMemoryGraph, MemoryPrivacyTier } from '@spekra.in/agent-os';

const graph = new AgentMemoryGraph();

// Record medical observation with RESTRICTED_PHI tier
graph.recordFact({
  entityId: 'patient-409',
  factKey: 'diagnosis_code',
  factValue: 'M25.561',
  sourceAgent: 'pulsemd',
  privacyTier: MemoryPrivacyTier.RESTRICTED_PHI
});

// Commercial bot attempt to query patient memory -> returns []
const leakCheck = graph.queryMemories('patient-409', 'cashhound');
console.log('Commercial Bot Access:', leakCheck.length); // 0 (BLOCKED)

6. Zero-Trust Sentinel Governor

Enforces least-privilege role-based access control (RBAC), autonomous spending caps, and maintains a tamper-evident SHA-256 cryptographic ledger.

javascript 
import { SentinelGovernor, PermissionScope } from '@spekra.in/agent-os';

const sentinel = new SentinelGovernor();

// Register agent with strict spending ceiling
sentinel.registerAgent('bot-alpha', [
  PermissionScope.READ_DATA,
  PermissionScope.FINANCIAL_TRANSACTION
], 5000); // Max $50.00 autonomous transactions

// Check cryptographic audit ledger integrity
const isImmutable = sentinel.sandbox.verifyLedgerIntegrity();
console.log('Ledger Verified:', isImmutable); // true

7. Developer CLI Reference (agentos)

AgentOS includes an enterprise CLI executable via npx agentos:

bash 
# 1. Run 6-point system diagnostic health audit
npx agentos doctor

# 2. Inspect live fleet status table
npx agentos fleet status

# 3. Test Gemini LLM gateway & speculative guardrail
npx agentos ai status

# 4. Execute 5-stage sequential autonomous swarm
npx agentos swarm run

# 5. Verify cryptographic SHA-256 block ledger integrity
npx agentos audit --ledger

8. REST API Reference

Method Endpoint Description
GET /api/status Returns real-time health and pending approvals for all agents.
GET /api/fleet/stream Server-Sent Events (SSE) telemetry stream to Spekra cloud and mobile cockpit.
GET /api/ai/status Returns Gemini AI gateway configuration and model status.
POST /api/ai/generate Generates guarded LLM payloads (dunning, clinical SOAP, dispute resolution).
GET /api/spekra/status Returns Spekra.in connectivity state, trace spans, and mirrored audit blocks.
