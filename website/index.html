Questions & Answers

Frequently Asked Questions

Everything you need to know about security, deployment models, and compliance boundaries.

What makes AgentOS different from basic LLM agent frameworks? ▼
AgentOS is engineered for production safety and zero-liability autonomy. Basic frameworks execute raw unverified strings; AgentOS enforces speculative verifiers for penny-exact minor unit math, scans messages for prohibited coercive debt collection phrases, and gates high-value transactions behind Secure Enclave FaceID biometrics.
How are healthcare facts kept separate from commercial agents? ▼
The AgentMemoryGraph enforces four cryptographic privacy partitions: PUBLIC, ORGANIZATION, CONFIDENTIAL, and RESTRICTED_PHI. Clinical scribe data from PulseMD is strictly sealed in RESTRICTED_PHI, which commercial dunning or marketing agents (like CashHound or LocalRoar) are cryptographically denied access to read.
How does the self-healing engine recover from payment gateway rate limits? ▼
AgentSelfHealer continuously classifies tool and API errors. When a 429 Rate Limit or transient network error occurs, it executes intelligent exponential backoff with jitter. If the primary rail remains down, it automatically fails over to preconfigured secondary rails (e.g. Adyen) without dropping active tasks.
Where can AgentOS be hosted and deployed? ▼
AgentOS is cloud-agnostic. The server runs as a standard Node.js daemon (Node 20+) on any Linux VM, macOS machine, or Docker container. The static web dashboard and documentation deploy natively to Cloudflare Pages (via wrangler.json) or GitHub Pages. The mobile command center runs on iOS and Android via React Native and Expo.
